# React UI

Интерфейс симулятора находится в `src/` и читает данные напрямую из
`data/city.json`.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию Vite откроет локальный адрес вида `http://127.0.0.1:5173/`.

## Сборка

```bash
npm run build
```

Собранные файлы попадают в `dist/`; эта папка не коммитится.
