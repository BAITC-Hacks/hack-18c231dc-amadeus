# React UI

Интерфейс в `src/` получает данные и результаты через HTTP API. Адрес бэкенда
задан только в константе `API_BASE_URL` в `src/api.js`.

## Запуск

Бэкенд (активируйте Python-окружение):

```bash
uvicorn api.main:app --reload
```

В другом терминале из корня проекта (Node.js 22):

```bash
npm ci
npm run dev
```

Откройте **http://localhost:5173/**. Vite использует фиксированный порт: если он
занят, запуск завершится ошибкой, чтобы не перейти на порт, отсутствующий в CORS.
Важно использовать `localhost`, поскольку `127.0.0.1` — другой origin.

## Сценарий

1. Интерфейс загружает районы, бюджет, каталог и базовый Score через `/api/config`.
2. Выберите пять решений или нажмите «Пример». Для городской меры район отключён,
   а в запрос отправляется `district: null`.
3. Нажмите «Рассчитать». `/api/simulate` возвращает Score и значения до/после;
   при `valid: false` интерфейс показывает причины и не отображает итоговый Score.
4. Нажмите «Объяснить результат». Ответ `/api/explain` отображается по разделам.
   При `ai_generated: false` видна отметка «Шаблонное объяснение — AI недоступен».
5. Изменение решений сбрасывает старый результат и отменяет ожидающий запрос.
   Для нового набора необходимо снова нажать «Рассчитать».

В браузере нет формулы Score или копии валидатора: расчёт и проверку выполняет
бэкенд. Во время выбора интерфейс суммирует только стоимость для индикатора бюджета.
Показатели, разницы и оценки районов берутся из ответа сервера.

Объяснение запрашивается только по кнопке; при настроенном OpenAI на сервере это
может вызвать платный запрос. Ключи остаются на бэкенде и не передаются браузеру.

## Проверка и сборка

```bash
npm test
npm run build
```

Тесты HTTP-клиента используют подмену fetch и не обращаются к OpenAI.
Сборка находится в `dist/`. Для локального просмотра сборки:

```bash
npm run preview
```

Откройте http://localhost:3000/ — этот origin также разрешён бэкендом.
