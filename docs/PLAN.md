## 2. MVP

Сценарий от входа до результата: открыть страницу → увидеть бюджет, районы и каталог мероприятий → выбрать по одному мероприятию в каждом из 5 направлений → система не даёт выйти за бюджет → нажать «Рассчитать» → получить Astana QoL Score до/после, разбор сильных сторон, рисков и компромиссов, плюс рекомендацию агента.

Если останется время, в порядке ценности:

1. Визуализация изменений по районам (полоски до/после) — усиливает критерий «решения влияют на показатели».
2. AI-рекомендация альтернативного сценария с пересчётом — уже заложена в агента, останется вывести в UI.
3. Моделирование неожиданного городского события с перераспределением бюджета.

## 3. Архитектура и стек

Стек: **Python 3.14 + FastAPI + uv**, официальный `openai` SDK, pytest. Фронтенд — один статический HTML с ванильным JS, который отдаёт сам FastAPI.

Почему без React и сборки: критерий «воспроизводимость» весит 25 баллов. `uv sync && uv run uvicorn app.main:app` — две команды, ноль шагов сборки, никакого `npm install` у эксперта.

```
app/
  main.py         FastAPI, отдаёт статику и API
  data.py         загрузка синтетического датасета
  scoring.py      детерминированный движок QoL Score
  agent.py        слой OpenAI: анализ и рекомендации + демо-режим
  models.py       Pydantic-схемы запросов и ответов
data/
  districts.json  5 районов × 5 показателей
  measures.json   20 мероприятий (по 4 на направление) со стоимостью и эффектом
static/index.html единственная страница
tests/            pytest
```

**Разделение ответственности — ключевое решение.** Score считает детерминированный движок, а не LLM. Модель объясняет и рекомендует, но не выдумывает числа. Это даёт воспроизводимость (одинаковый вход → одинаковый Score) и снимает риск галлюцинаций в оценке.

**Где здесь agentic AI.** Агент получает сценарий и инструмент `score_scenario(decisions)`. Он вызывает его несколько раз: считает текущий сценарий, пробует альтернативы в рамках того же бюджета, сравнивает и возвращает обоснованную рекомендацию. Это настоящий tool calling, а не один промт.

**Демо-режим.** `DEMO_MODE=1` (значение по умолчанию, если нет `OPENAI_API_KEY`) — объяснение строится по фактическим дельтам показателей, честно помечается как «разбор без LLM». Эксперт проверяет весь сценарий без своих ключей — это требование п. 5.6.6 Положения, а не удобство.

## 6. Риски и запасной вариант

| Риск | Что делаем |
|---|---|
| Нет ключа OpenAI или сеть на площадке легла | Демо-режим уже основной путь, он не заглушка. Проект полностью проходится без ключа |
| Не успеваем UI | Запасной вариант: сценарий проходится через `/docs` (Swagger UI даёт FastAPI бесплатно). README описывает именно его |
| Агент с tool calling не заводится | Откат на один вызов LLM с готовыми дельтами на входе. Интерфейс `agent.py` не меняется |
| Второй участник не подключился | Порядок работы: сначала движок и API, потом UI. Соло-путь укладывается в срок, UI — первое, что упрощается |
